# Assistant Beta

Downloads for Assistant Beta testers. You'll also need your tester code from Donavian, and the setup guide he sent you walks through every step.

| Your computer | Download |
|---|---|
| **Newer Mac**, bought late 2020 or later (Apple chip) | [Assistant-Beta-Newer-Mac-Apple-chip.dmg](https://github.com/donavianlorio-1999/assistant-beta/releases/latest/download/Assistant-Beta-Newer-Mac-Apple-chip.dmg) |
| **Older Mac**, bought 2020 or earlier (Intel) | [Assistant-Beta-Older-Mac-Intel.dmg](https://github.com/donavianlorio-1999/assistant-beta/releases/latest/download/Assistant-Beta-Older-Mac-Intel.dmg) |
| **Windows** 10 or 11 | [Assistant-Beta-Windows.exe](https://github.com/donavianlorio-1999/assistant-beta/releases/latest/download/Assistant-Beta-Windows.exe) |

Not sure which Mac you have? Click the Apple menu, then **About This Mac**. "Chip: Apple" means the newer-Mac file; "Processor: Intel" means the older-Mac file.

Each file is about 500 MB, because the voice and hearing are built in.

This is an early beta. Your questions go through Donavian's server to the AI and back, and none of it is kept.
